# Cont/x

**A Desktop and Web Application for Enforcing Academic Integrity through System-Wide Lockdown and On-Device Automated Assessment**

## Project Overview

Cont/x is a Windows desktop and web application designed to strengthen academic integrity in programming examinations for Philippine computing education. It combines **secure exam lockdown** with **automated programming assessment** into a unified platform, allowing educators to administer, monitor, and evaluate programming-based examinations efficiently.

## Project Goal

Cont/x aims to provide computing educators with a practical, scalable, and cost-effective solution for conducting secure programming examinations while improving efficiency in assessment and maintaining academic integrity.
